## Project Title

*Teen Phone Addiction Analysis - BAIS: 2800 Project - My First Repository*

## Description

This project examines the key factors associated with smartphone addiction among 18-year-old high school students. Using a Kaggle dataset containing survey responses, we explored how daily habits—such as screen time, social media usage, gaming, sleep hours, anxiety, and depression levels—relate to an individual's phone addiction score.

Through data cleaning, sample filtering (randomly sampling 300 students using Excel's RAND function), and regression analysis, we identified the strongest predictors of smartphone dependence.
